🐙 Git + GitHub

Git gestiona l'historial i les branques; GitHub allotja el repositori i serveix la web amb GitHub Pages.

Git GitHub Pages

Per què GitHub Pages?

  • Permet publicar contingut web estàtic directament des d'un repositori.
  • Facilita separar el codi del projecte de la documentació pública.
  • La branca gh-pages és una opció habitual per a aquest tipus de desplegament.
