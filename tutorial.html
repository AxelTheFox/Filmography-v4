Com consultar el projecte

Una guia breu per entendre el flux general i, posteriorment, el procés de publicació amb GitHub Pages.

1. Accedeix a l'aplicació

Obri la versió de desenvolupament del projecte original i identifica la pantalla principal.

2. Explora el contingut

Navega per les diferents seccions disponibles i prova les funcionalitats que implemente l'aplicació.

3. Consulta un element

Obri una pel·lícula o element del catàleg per veure la informació disponible en la vista de detall.

4. Revisa aquesta documentació

Utilitza les pàgines Projecte i Tecnologies per conéixer l'estructura i el stack.

Publicar una actualització

git checkout gh-pages

# editar fitxers HTML/CSS/imatges

git add .
git commit -m "Update GitHub Pages documentation"
git push origin gh-pages

Comprovar el desplegament

Després del push, revisa Settings → Pages i comprova que la font de publicació és gh-pages i la carpeta /(root). Finalment, obri l'URL de GitHub Pages del repositori.
